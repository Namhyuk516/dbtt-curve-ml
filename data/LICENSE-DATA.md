measurements) are made available under the Creative Commons Attribution 4.0 International licence (CC BY 4.0),
https://creativecommons.org/licenses/by/4.0/.

The literature values were transcribed from the 40 publications listed in `TableS1_sources.csv`; please cite the original
publications when using individual data, and cite this repository (Zenodo DOI in the README) when using the compiled database.
